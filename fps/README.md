# 残照 AFTERGLOW

浏览器里运行的小关卡 FPS，场景是一个集装箱码头，可选白天、黄昏、日落、雨天、夜晚五个时段。

**整个游戏就是一个文件：`fps/index.html`，双击即可在浏览器里玩。** 里面内联了 three.js 和全部游戏代码，运行时不联网、不加载任何外部资源。贴图、模型、音效全部由代码在启动时现场计算。

## 渲染

- **程序化 PBR 材质**：所有贴图都由 GPU 着色器在启动时生成（反照率、法线、AO/粗糙度/金属度），没有任何外部图片。包括带积水和裂缝的混凝土、砖墙、波纹钢板、集装箱漆面锈蚀、木纹、迷彩布料等。
- **真实几何细节**：集装箱和板房的波纹板是真实几何体，低角度阳光能在波纹上投下细小阴影；枪械用圆角几何体建模。
- **光照**：低角度太阳和 4K 阴影贴图，环境光由天空 PMREM 提供（IBL），钠灯和窗户作补光。
- **大气**：解析积分的高度雾，带太阳前向散射；天空使用 Rayleigh/Mie 大气散射模型和体积云。
- **积水实时反射**：镜像相机以半分辨率渲染场景，地面在积水和湿润处用它替换环境高光，集装箱、无人机和夕阳都会倒映在水里（高 / 极致画质）。
- **夜晚**：星空、月亮与月晕、城市光污染，路灯和壁灯带体积光锥，战术手电可投射实时阴影。
- **雨天**：GPU 计算的雨丝（绕镜头循环，不占 CPU）、积水涟漪、地面溅射、所有表面变湿变暗、阴云天空、闪电与延迟雷声、雨声。
- **动态分辨率**：根据帧时间自动在 55%–100% 之间调整渲染分辨率，按 F 可查看当前比例。
- **后期**：镜头鬼影与光晕、GTAO 环境光遮蔽、基于深度遮挡的屏幕空间体积光、HDR Bloom、ACES 色调映射、分离色调调色、色差、暗角、胶片颗粒，以及受伤和低血量效果。
- **第一人称武器**：独立的视野和投影，深度被压缩到近端，所以不会穿进墙里。还有程序化的摆动、呼吸、后坐力弹簧、开镜、冲刺姿态和完整的换弹动画（弹匣脱落、左手跟随）。
- **特效**：火花、尘雾、木屑、弹孔贴花、曳光弹、物理弹壳、爆炸碎片和烟柱。

## 玩法

共五波，三种敌人：

- **哨兵无人机**：分为压制、包抄、骚扰三种角色，包抄型会绕到你视野的侧后方；同时最多两架充能开火，攻击前眼睛发亮。打中旋翼会让它失衡打转、掉高度、暂时无法开火（伤害 ×1.3）。
- **重型哨兵**：更大、更耐打，四连发。
- **四足机甲 STRIDER**（第三波起）：程序化 IK 步态的地面单位，炮塔追踪玩家打连发，丢失视线会主动逼近。正面装甲减半伤害，背部发光的能量核心受 3 倍伤害，适合绕后打。
- **自爆蜂**：红色发光，高速直冲玩家，越近蜂鸣越急，贴身后引爆；在近处击落它同样会炸到自己，爆炸还会波及附近的无人机。

- **母舰 WARDEN（第五波 Boss）**：四个旋翼舱是弱点，全部打掉后护盾失效，才能攻击下方核心。它会用激光扫射（先有细线锁定预警，掩体可以挡住），旋翼舱发射等离子弹，并定期放出自爆蜂。顶部有血条和旋翼舱计数。

场上有 6 个可引爆的红色油桶：打穿后会先漏火燃烧约 2 秒再爆炸，爆炸会波及附近的无人机和 Boss，引爆相邻油桶，也会伤到离得太近的你。

被击落的无人机会失控旋转、拖着火焰和浓烟坠落，撞到地面或集装箱才爆炸。手雷（G）会在地面和墙面上弹跳，2.4 秒后爆炸，伤害随距离衰减，隔着掩体减弱，离得太近也会伤到自己。

仓库的卷帘门卡在半开位置，可以钻进去：里面有两排装满货物的托盘货架、钢柱、悬挂工矿灯和中间的掩体。无人机只能透过门洞开火，自爆蜂会追进去，适合短暂喘息和补给。

场上有 7 个补给点（弹药箱、医疗包），走过去自动拾取，35 秒后刷新，地面光圈方便辨认。菜单可选难度（简单 / 普通 / 困难），影响受到的伤害、敌人血量、开火频率和得分倍率，可以随时切换。

结算界面给出评级（S/A/B/C）、详细数据和 8 枚勋章（毫发无伤、连杀大师、神射手、爆破专家、机甲猎手、近身格斗、远程狙杀、屠龙者）。通关后可以进入**无尽模式**：波次程序生成、逐渐加码，每 5 波来一次母舰，记录最高波数。

击杀计分，4 秒内连续击杀会叠加连杀倍率；通关时按用时和剩余生命加奖励分，最高分保存在本地。玩家生命值会自动回复，每波结束后补给弹药和手雷。配乐同样是实时合成的动态音乐：平时只有氛围铺底，交战时加入贝斯和鼓，Boss 战和低血量时叠加琶音，菜单里可以调音乐音量。步枪有固定可学的后坐力图案（先上跳，再左右蛇形），连续射击后枪口会冒余烟。所有音效都用 WebAudio 实时合成，带 HRTF 空间定位和户外混响。

|---|---|

| Q / E | 向左 / 向右探头（侧身瞄准，贴墙时自动限制幅度） |

菜单里可以选择时段（白天 / 黄昏 / 日落 / 雨天 / 夜晚，默认黄昏）和画质（低 / 中 / 高 / 极致），也可以用 URL 参数指定，例如 `?t=day&q=ultra`。开镜灵敏度可以单独调节。

屏幕顶部的罗盘会标出所有无人机的方位：红色为哨兵，大号为重型，闪烁的橙色为自爆蜂。

## 开发

源码在 `src/`，HTML 模板是 `src/index.template.html`。唯一的依赖是 three.js（含其自带的 addons），只在构建时需要。

```bash
cd fps
npm install
npm run build   # 把 src/ 和 three.js 打包，内联进单文件 index.html
npm run dev     # 同上，不压缩
```
