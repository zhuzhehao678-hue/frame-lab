# Wander & Linger｜漫游

一个高审美的慢旅行单页网站，按照 CRISPE 提示词实现，包含三个设计方向：

| 页面 | 方向 | 关键词 |
| --- | --- | --- |
| `index.html` | 总览 | 三个方向的预览、对比与推荐 |
| `zen.html` | A 侘寂·静 | 米白 + 墨绿，宋体，大留白，日式杂志感 |
| `sun.html` | B 地中海·暖 | 奶油白 + 陶土橙 + 海蓝，拱门画框，度假感 |
| `noir.html` | C 暗夜·奢 | 炭黑 + 香槟金，Bodoni，宽银幕电影感 |

## 本地预览

纯静态文件，无需构建：

```bash
cd travel
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 结构

- `assets/base.css`：三个方向共用的布局骨架（12 列栅格、杂志式错落网格、横向滚动、信纸表单、动效）。
- `assets/theme-*.css`：每个方向通过 CSS 变量覆盖色彩、字体、圆角，并添加各自的装饰细节。
- `assets/main.js`：无依赖的原生 JS，负责导航显隐与毛玻璃、滚动进入动效、横向滚动（按钮 / 拖拽 / 进度条）、评价轮播和表单反馈。

图片来自 Unsplash；动效在系统开启"减少动态效果"时会自动关闭。
